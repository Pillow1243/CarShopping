# رزومه امیر رستگاری — Amir Restagari · Mechanic Resume Site

> ⚠️ **نمونهٔ تستی / Demo data.** نام، شماره تماس، ایمیل، آدرس، قیمت‌ها، نظرات مشتریان و همهٔ آمار **ساختگی (fake)** هستند و فقط برای نمایش و تست رابط کاربری نوشته شده‌اند. تصاویر هم تولید هوش مصنوعی‌اند.

سایت رزومهٔ یک **استادکار ارشد خودرو / مکانیک حرفه‌ای** — راست‌چین (RTL)، فارسی، با تم تیرهٔ لوکس.

**ساخته‌شده بدون هیچ کتابخانه‌ای:** HTML + CSS + JavaScript خالص (Vanilla). بدون React، بدون Tailwind، بدون build tool اجباری.

---

## 🚀 اجرا و انتشار

| کار | روش |
|---|---|
| دیدن آنلاین | https://pillow1243.github.io/CarShopping/ |
| اجرای محلی | `python3 -m http.server 8080` بعد باز کردن `http://localhost:8080` از ریشهٔ ریپو |
| باز کردن آفلاین | فایل `standalone/resume-standalone.html` (تک‌فایل: CSS، JS، فونت و تصاویر داخل خودش inline است — با دابل‌کلیک روی هر دستگاهی باز می‌شود) |
| بازسازی خروجی‌ها | `python3 scripts/build.py` (تصاویر را بهینه می‌کند، نسخهٔ `public/` و `standalone/` را می‌سازد و ارجاع‌های شکسته را چک می‌کند) |
| تست کامل مرورگر | `pip install playwright && python3 -m playwright install chromium && python3 scripts/qa.py` |

### ساختار

```
├── index.html                 ← نسخهٔ منتشرشده (GitHub Pages از همین ریشه سرو می‌کند)
├── css/styles.css             ← دیزاین‌سیستم، RTL، حالت چاپ/رزومه
├── js/main.js                 ← همهٔ تعامل‌ها، ماژولار در ۲۳ بخش
├── assets/fonts/*.woff2       ← وزیرمتن (OFL) — آفلاین کار می‌کند
├── assets/img/*.jpg           ← تصاویر بهینه‌شده (AI-generated)
├── src/                       ← سورس قابل‌ویرایش (همین فایل‌ها قبل از build)
├── standalone/                ← خروجی تک‌فایل (build.py)
└── scripts/{build.py,qa.py}   ← خط ساخت + تست خودکار رانتایم
```

## ✨ چیزی که در سایت هست

**بخش‌ها:** هیرو با داشبورد «Diagnostic Cluster» · آمار عملکرد · درباره من · میز مهارت (نوار + رادار شش‌محوری) · جعبه‌ابزار · ۹ خدمت · تایم‌لاین ۱۷ سالهٔ سوابق · تحصیلات و گواهینامه‌ها · گالری نمونه‌کار با فیلتر و **اسلایدر قبل/بعد** · نظرات مشتریان با امتیاز · تعرفه‌ها با سوئیچ تخفیف ناوگان · سؤالات متداول · فرم رزرو وقت · فوتر.

**تعامل‌های امضایی (همه vanilla):**

- ⏱ **تاخومتر زنده** که عقربه‌اش با **اسکرول صفحه** حرکت می‌کند و نوار طلاییِ_arc_ هم‌زمان پر می‌شود
- 🔥 **ذرات جرقه/غبار روی canvas** در هیرو، با pause خودکار وقتی بیرون viewport است
- ⌨️ **افکت تایپ‌رایتر** برای عنوان‌های شغلی
- 🖱 **کرسر سفارشی** + دکمه‌های مغناطیسی (magnetic) + نور نقطه‌ای روی کارت‌ها
- 🔊 **صدای استارت موتور** ساخته‌شده با Web Audio API (بدون هیچ فایل صوتی!) — با دکمهٔ بلندگو فعال می‌شود
- 📅 **ویجت ظرفیت زنده**: بر اساس ساعت واقعی، وضعیت «باز / بسته / جمعه تعطیل» و جدول ساعت کاری با تقویم هجری شمسی (`Intl` با `calendar: persian`)
- 🧾 **خروجی PDF واقعی**: استایل `@media print` سایت را به یک رزومهٔ A4 تمیز تبدیل می‌کند (دکمهٔ «دریافت رزومه PDF»)
- 📆 **فایل .ics** برای اولین وقت خالی، سمت کلاینت تولید می‌شود
- 🌓 تم روشن/تاریک + ۳ پالت تأکید (طلایی / آتشین / فیروزه‌ای) با ذخیره در `localStorage`
- ✅ اعتبارسنجی کامل فرم با اعداد فارسی، حالت **کاهش حرکت**، `aria-*`، فوکوس‌رینگ و `skip link`

**دادهٔ ساخت‌یافته:** JSON-LD از نوع `Person` + `meta`های Open Graph برای SEO.

## 🎨 تصمیم‌های فنی

- **RTL اصلی است، نه چسبانده‌شده:** از `inset-inline-*`، `margin-inline`، `border-inline` و `clip-path` جهت‌آگاه استفاده شده، پس منطق اسکرایدر مقایسه و جهت انیمیشن‌ها با `direction` سازگار است.
- **بدون CDN:** فونت وزیرمتن به‌صورت `woff2` لوکال سرو می‌شود؛ سایت آفلاین و بدون درخواست بیرونی کار می‌کند (`failed requests: 0` در تست خودکار).
- **کارایی:** `IntersectionObserver` برای همهٔ انیمیشن‌ها (بدون listener روی scroll به‌جز دو مورد throttle‌شده با `requestAnimationFrame`)، `content-visibility` دوستانه، `loading="lazy"` برای تصاویر، و تصویر هیرو با `fetchpriority="high"`.
- **دسترس‌پذیری:** سِمانتیک، `aria-current` روی ناوبری اسکرول‌اسپای، Escape برای منو/لایت‌باکس، ناوبری کامل با کیبورد در لایت‌باکس و اسلایدر.

## 🧪 وضعیت تست

`scripts/qa.py` با Chromium بی‌سر این‌ها را بررسی می‌کند (و در آخرین اجرا **۳۰ بررسی PASS، صفر خطای کنسول، صفر درخواست شکسته** شد): حذف preloader، بارگذاری فونت، تایپ‌رایتر، شمارنده‌های فارسی، تولید تیک‌های گیج، رسم رادار، انیمیشن نوارهای مهارت، اسکرول‌اسپای، تم/پالت، فیلتر گالری، لایت‌باکس، درگِ قبل/بعد، کاروسل نظرات، آکاردئون، سوئیچ تخفیف، اعتبارسنجی و ثبت فرم، دانلود ICS، جدول ساعت کاری، نبود سرریز افقی در دسکتاپ/موبایل، رندر نسخهٔ چاپی و منوی موبایل.
